## 一、训练分化

### 1. 全身训练（Full Body）
- 每周 3 次
- 适合新手

### 2. 上下分化（Upper/Lower）
- 每周 4 次

### 3. Push Pull Legs（PPL）
- 高级训练方式

## 二、训练变量

- 持续增加训练刺激

## 四、恢复与过度训练

### 过度训练表现
- 疲劳
- 力量下降
- 睡眠差

### 恢复方式
- 睡眠
- 拉伸
- 按摩
