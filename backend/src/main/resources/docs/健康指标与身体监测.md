# 健康指标与身体监测

tags: [健康, BMI, 体脂率, 心率]

## 一、关键指标

### BMI（身体质量指数）
- 公式：体重 / 身高²
- 局限：无法区分肌肉与脂肪

### 体脂率
- 男性：
  - 健康：10~20%
- 女性：
  - 健康：18~28%

---

## 二、心率监测

### 静息心率
- 正常：60~100 bpm

### 最大心率
- 公式：220 - 年龄

---

## 三、睡眠质量

### 指标
- 入睡时间
- 深睡比例

---

## 四、饮水

- 建议：30~40 ml/kg

---

## 五、FAQ

Q：只看体重可以吗？
A：不够，应结合体脂率。

Q：如何判断健康？
A：综合指标评估。
